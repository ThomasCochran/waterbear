## Apps
| Shortcut | Action |
|---|---|
| Super + Enter | Terminal (kitty) |
| Super + Shift + Enter | Dropdown terminal |
| Super + B | Web browser |
| Super + E | File manager (Thunar) |
| Super + D | App launcher (Rofi) |
| Super + Alt + C | Calculator (qalculate in Rofi) |
| Super + S | Web search (Google, or DuckDuckGo once added in Install → Browsers) |
| Super + Alt + E | Emoji picker |
| Super + Alt + V | Clipboard history |
| Super + H | Keybind cheat sheet |
| Super + Shift + K | Search keybinds |
| Super + I | Status popup (time, battery, wifi, volume) |
| Super + W | Show / hide the status bar |
| Super + Alt + Space | Waterbear menu (themes, apps, settings, all shortcuts, update) |

## Windows
| Shortcut | Action |
|---|---|
| Super + Q | Close window |
| Super + Shift + Q | Force-kill window's process |
| Super + Space | Toggle floating |
| Super + Shift + F | Fullscreen |
| Super + Ctrl + F | "Fake" fullscreen (maximize) |
| Super + Arrows | Move focus |
| Super + Ctrl + Arrows | Move window |
| Super + Alt + Arrows | Swap windows |
| Super + Shift + Arrows | Resize window |
| Super + Left-drag / Right-drag | Move / resize with mouse |
| Alt + Tab | Cycle windows |
| Super + Ctrl + S | Window switcher (Rofi) |
| Super + G | Toggle window group |
| Super + Ctrl + Tab | Next window in group |

## Workspaces
| Shortcut | Action |
|---|---|
| Super + 1–0 | Go to workspace 1–10 |
| Super + Shift + 1–0 | Move window there and follow |
| Super + Ctrl + 1–0 | Move window there and stay |
| Super + Tab / Super + Shift + Tab | Next / previous workspace |
| Super + . / Super + , (or Super + scroll) | Next / previous workspace that has windows |
| Super + U | Show/hide scratchpad |
| Super + Shift + U | Send window to scratchpad |
| 3-finger swipe | Switch workspace |
