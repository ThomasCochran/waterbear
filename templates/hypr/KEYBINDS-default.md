KEYBINDS (Hyprland stock set)  ·  press q to close

This set has no lock-screen or screenshot shortcuts. For those (Ctrl + Alt + L to lock,
Super + Print for screenshots, and more), switch to the JaKooLit-style set in the menu:
Super + Alt + Space → Keyboard → Keybind set.

## Apps
| Shortcut | Action |
|---|---|
| Super + Q | Terminal (kitty) |
| Super + R | App launcher (Rofi) |
| Super + E | File manager (Thunar) |
| Super + Alt + Space | Waterbear menu (themes, apps, settings, shortcuts, update) |

## Windows
| Shortcut | Action |
|---|---|
| Super + C | Close window |
| Super + V | Toggle floating |
| Super + P | Pseudo-tile |
| Super + J | Toggle split direction |
| Super + Arrows | Move focus |
| Super + Left-drag / Right-drag | Move / resize with mouse |

## Workspaces
| Shortcut | Action |
|---|---|
| Super + 1–0 | Go to workspace 1–10 |
| Super + Shift + 1–0 | Move window to workspace 1–10 |
| Super + scroll | Next / previous workspace that has windows |
| Super + S | Show/hide scratchpad |
| Super + Shift + S | Send window to scratchpad |
| 3-finger swipe | Switch workspace |

## System
| Shortcut | Action |
|---|---|
| Super + M | Exit Hyprland |
| Left Alt + Left Shift | Switch keyboard layout |
| Media / volume / brightness keys | Work as normal |
