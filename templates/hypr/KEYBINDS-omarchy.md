KEYBINDS (Omarchy-style set)  ·  press q to close

Laid out like Omarchy's shortcuts, using Waterbear's apps. Omarchy-only extras (dictation,
reminders, screen recording, OCR, universal copy/paste, per-site web app keys) aren't included.

## Apps
| Shortcut | Action |
|---|---|
| Super + Enter | Terminal (kitty) |
| Super + Alt + Enter | Terminal with tmux |
| Super + Shift + Enter | Web browser |
| Super + Shift + B | Web browser |
| Super + Shift + Alt + B | Web browser (private) |
| Super + Shift + F | File manager (Thunar) |
| Super + Shift + N | Editor (Neovim) |
| Super + Shift + M | Music (Spotify) |
| Super + Shift + D | Docker (lazydocker) |
| Super + Shift + G | Signal |
| Super + Shift + O | Obsidian |
| Super + Ctrl + T | Activity (btop) |
